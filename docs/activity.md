# 访问记录

管理员通过独立的 `/admin` 页面管理邀请、查看访问记录。助手侧边栏保持原有入口。

## 邀请使用情况

邀请列表展示首次激活、最近访问、访问次数和提问次数。点击访客名称打开固定尺寸的访问详情弹窗；访问记录标签页支持按访客、行为和最近7天、30天或全部时间筛选，并分页加载。

- 首次激活取该邀请生成的首个访客身份的创建时间。
- 最近访问取最后一次浏览行为或提问时间。
- 同一身份、同一绑定浏览器，连续30分钟没有新行为后，下次访问计为新的一次。刷新与并发标签页共用访问。
- 提问次数来自实际持久化的 `chat_runs`，重复提交同一运行不会重复计数。
- 重置设备后，邀请下的新旧访客身份分别保持聊天隔离，访问统计按邀请汇总。

## 记录内容

| 行为 | 来源 |
| --- | --- |
| 邀请激活、登录 | 后端认证成功后记录 |
| 查看页面、项目介绍标签 | 前端在页面实际挂载或切换时上报 |
| 查看文档原文 | 文档详情页及引用预览 |
| 查看数据与SQL | 查询详情弹窗、SQL标签 |
| 查看测试用例 | 用例详情 |
| 发送问题、回答完成/失败/停止/中断 | 现有运行记录；工具名称来自保存的实际调用 |

浏览事件保存在 PostgreSQL `access_visits`、`access_events` 表。时间使用服务端时间，界面按浏览器本地时区显示。新表随应用启动自动创建。

## 身份与数据

`POST /api/v1/activity/events` 复用登录 Cookie 和设备签名。身份由认证结果确定；前端只能提交规定的浏览行为，不能提交登录、回答结果或其他访客身份。事件 ID 在同一身份下幂等，数据库行锁使并发标签页共享同一次访问。

页面路径、项目标签和测试用例使用固定目录校验；文档名称由数据库读取，查询结果校验当前访客归属。仅保留页面或对象标识和浏览器/系统类型，聊天正文、SQL正文、邀请令牌、密钥与完整URL参数不进入访问事件。

`GET /api/v1/admin/activity` 仅管理员可用，支持邀请、行为、起止时间和分页参数。运行记录合并到时间线时只选择状态、时间和工具名称。前端上报采用有限重试，登录记录异常不会阻止正常登录。
