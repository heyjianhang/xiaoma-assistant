## 已知不足与下一轮验收

- 一次复杂任务曾从纯 SQL 合计扩展到不必要的文档核对并达到调用上限；补充规则后重试成功。这不是“路由已完美”的证据。
- CLI 真实多轮查询曾复用旧 `context_id` 被拒绝，重新查看结构并链接后完成；当前 SOP 仍值得针对跨轮上下文优化。
- 完整10份 PDF 与配套 Markdown 现已纳入交付资料，但未全部重新上传并做真实模型回归。尤其月报2%与数据库8%的冲突、两版制度、续页表格、小样本等，需要按 [验收清单](../tests/acceptance/cases.json) 逐项记录。
